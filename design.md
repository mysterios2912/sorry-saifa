# Design System — Sorry Saifa

## Inspiration
Minimal one-page love letter site. Single illustrated flower hero, soft pastel background, sparse uppercase tracking typography.

## Colors
- Background: soft blush pink `#fce8e8` → light mint `#e8f4f0` gradient (top to bottom)
- Primary text: `#5a4a4a` (warm dark rose-brown)
- Accent: `#c9372c` (deep red for names)
- Flower: deep blue `#1a3a8f` petals, yellow `#f5c518` stamens, green `#4a7c59` stem
- Subtle: `#f0d0d0` for decorative elements

## Typography
- Font: `Cormorant Garamond` (display, elegant, romantic) + `Lato` (body, clean)
- Header: uppercase, wide letter-spacing (0.3em), small size ~13px
- Hero title: large, italic, serif — ~72px
- Body: 18px, generous line-height 1.9

## Layout
- Full viewport sections, vertically scrolled
- Centered content, max-width 680px
- Generous whitespace — breathing room between elements

## Motion
- Flower blooms from center on load (SVG path draw + scale animation)
- Petals float down gently in background (CSS keyframes)
- Sections fade+slide up on scroll (Intersection Observer)
- Scroll indicator bounces at bottom of hero

## Style Keywords
Minimal, romantic, soft, intimate, hand-crafted feel
